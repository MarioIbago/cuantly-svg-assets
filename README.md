# Cuantly SVG Assets

Public asset repository for visual resources used across Cuantly-related projects, including Cuantly, Cermatín, and Billqo.

## Contents

- `Cuantly (1).svg` — Cuantly vector asset.
- `Cuantly (2).svg` — alternate Cuantly vector asset.
- `Cermatin (1) .svg` — Cermatín vector asset.
- `billqo-assets/` — Billqo image assets, including app/icon, transparent mark, and Open Graph image.

## Usage

Assets can be referenced directly from the repository or downloaded for use in compatible projects. When using raw GitHub URLs in an application, pin to a commit when you need a stable, immutable asset version.
